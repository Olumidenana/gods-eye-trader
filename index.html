What gets tested, and how much

Each test downloads real Deriv candles for the market, 5,000 at a time, back to the start of the period below, then replays every candle through the model (or the model with a building block switched on) you chose: the same rules as the live signals, with the spread charged, and when one candle touches both the stop and the target, the stop counts.

Want the trades inside your Deriv MT5 account, where you can watch them in MT5? Install the ICT Flux robot: it places the same signals there, with stop loss, TP1 and TP2, inside the limits you set. MT5 must stay open on a computer (or a VPS) that stays on; the MT5 phone app cannot run robots.

  1. Download the robot below. In MT5: File → Open Data Folder → MQL5 → Experts, and put the file there.
  2. In MT5: Tools → Options → Expert Advisors, tick Allow WebRequest for listed URL, add https://ictflux.app, OK.
  3. In the Navigator panel, right-click Expert Advisors → Refresh, then drag ICTFluxMT5 onto any one chart. Set your risk, tick Allow Algo Trading, OK.
  4. Click Algo Trading in the toolbar so it turns green. The Experts tab (bottom) shows every trade it places or skips.

ⓘDeriv executes these as multiplier contracts: the bot sizes the stake and multiplier so that hitting the engine's stop loses your chosen risk, and the take-profit sits at the engine's target. Deriv multipliers have no resting entry orders, so the bot rests the plan itself: it reads the live price from Deriv's public feed and, when price touches the limit, enters at market. Before every entry it checks that the plan still holds: price is not through the stop or past the first target, it has not run more than 0.25R from the entry (the bot does not chase), it is not more than 0.75R through the entry toward the stop (the idea is failing, not retracing), and the target still pays the minimum reward to risk (1.5R in this page's bot, the setting you chose for the always-on bot). The stop and the target stay on the plan's price levels, measured from where it entered. SIZE DOWN and STAND DOWN plans are not traded. Rules, not hunches

An ICT trading engine that shows its working.

ICT Flux turns the ICT Time-and-Price model into explicit, tested rules. Like ICT, it builds the story first: where price came from, where it is going and whether it sits in premium or discount, and it stands aside when there is no story to trade. Then it looks for trades only inside killzones, waits for a liquidity raid that fits the story and a real shift in structure, lets a judgement matrix rule on the trade, sizes every position from hard risk limits, and logs the rule behind every decision. The backtester and the live runner run exactly the same code.

How a trade happens

Build the story first

Where price is coming from, where it is going (the draw on liquidity: the prior day or week extreme, or a longer range) and whether it sits in premium or discount. No clear draw, a draw already reached, or the daily and weekly draws pulling opposite ways: stand aside.

Wait for the window

Only inside a killzone for that market: London 02:00–05:00, NY AM, or NY PM. Never in the lunch hour or around red-folder news.

A raid that fits the story

Price runs beyond a reference level (Asian range, prior-day high/low) in the right order. That's the stop-hunt ICT calls a sweep. In a bullish story only a raid on sell-side liquidity counts; a raid the other way is ignored.

Structure shifts

Price displaces back through a recent swing with large candles, leaving a 3-candle fair value gap in premium (shorts) or discount (longs).

Limit order in the gap

Entry at the gap edge or its 50% level. Stop beyond the raid. Target the draw from the story, with partials at the pools on the way, minimum 1.5R.

The matrix rules on it

The judgement matrix scores the trade out of 100: PULL THE TRIGGER, SIZE DOWN or STAND DOWN. The ICT 2022 Model never places a STAND DOWN setup, and the bots trade only PULL THE TRIGGER plans.

Entered while the plan holds

A resting limit is entered the moment price touches it, checked against the live price first. Through the stop, past the first target, run away from the entry or failing: it does not chase and does not enter.

Risk decides the size

1% base risk, halved after a loss, quartered after two. Daily and weekly loss floors stop everything; nothing overrides them.

Managed to the end

Stop trimmed at 50% of target, breakeven at 75%, partials at the first pool, flat by 16:00 NY and before the weekend.

Run it yourself

Pure Python 3.11+. Works with MetaTrader 5 (official API) or MetaTrader 4 (included bridge EA), normally on a Windows VPS.

1 · Test and validate

# run the test suite
python -m unittest discover -s tests -t .

# backtest with an HTML report of every trade
python -m ict_trader --config my.toml backtest \
  --data data/EURUSD_M5.csv --news calendar.csv \
  --report reports/eurusd.html

# walk-forward: only out-of-sample results count
python -m ict_trader --config my.toml walkforward \
  --data data/EURUSD_M5.csv --news calendar.csv \
  --grid examples/grid.example.json

  --platform mt5 --news calendar.csv --execute
